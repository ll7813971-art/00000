# Pac-Man 2D

Pac-Man jugable en un solo archivo: **`pacman.html`**. Ábrelo en cualquier navegador; no hace falta instalar nada.

- **Controles:** flechas o WASD para moverte, Enter para empezar, P para pausar y M para quitar el sonido.
- **En el móvil:** desliza el dedo sobre la pantalla o usa la cruceta.

Igual que el original: el mismo laberinto de 28x31 con 240 puntos y 4 píldoras de poder, y cada fantasma con su propia forma de perseguirte (Blinky, Pinky, Inky y Clyde). Los fantasmas alternan entre dispersarse y perseguirte, y Blinky acelera ("Cruise Elroy") cuando quedan pocos puntos. Además: el túnel, las frutas, una vida extra a los 10.000 puntos, los niveles cada vez más rápidos y el récord guardado en el navegador.
